# 🏧 ATM Cash Usage Analytics Dashboard

## 📌 Project Overview
The ATM Cash Usage Analytics Dashboard is a Data Analytics project developed to analyze ATM transaction patterns, cash withdrawal trends, failed transactions, and location-wise ATM usage using Power BI and SQL.

This project helps understand customer transaction behavior and provides insights that can support better ATM cash management and operational monitoring.

---

# 🎯 Objectives
- Analyze ATM transaction activity
- Monitor failed transactions
- Identify high-usage cities and locations
- Visualize transaction trends using dashboards
- Generate business insights from ATM data

---

# 🛠️ Tools & Technologies Used
- 📊 Power BI
- 🗄️ MySQL
- 📑 Excel
- 📈 Data Analytics

---

# 📂 Dataset Information
The dataset contains 2000+ ATM transaction records with details such as:
- ATM ID
- City
- Transaction Type
- Transaction Amount
- Response Code
- Location Type
- ATM Status

---

# 📊 Dashboard Features
## KPI Cards
- Total Transactions
- Total Withdrawal Amount
- Failed Transactions
- Active ATMs

## Visualizations
- City-wise ATM Transactions
- Transaction Type Distribution
- Transaction Response Analysis
- Location-wise ATM Usage

## Interactive Features
- City Slicer
- Transaction Type Filter
- Dynamic Dashboard Interaction

---

# 🧠 Key Insights
- Kolkata recorded the highest ATM transaction activity
- Urban locations showed maximum ATM usage
- Cash Withdrawal was the most common transaction type
- Around 19% transactions failed due to response errors

---

# 🗄️ SQL Analysis
SQL queries were used to:
- Count total transactions
- Analyze withdrawal amounts
- Identify busiest ATMs
- Detect failed transactions
- Compare city-wise ATM activity
